# Ping Pong

A simple two-paddle Ping Pong game made with HTML, CSS, JavaScript, and Canvas. game include one computer and one human side .

## Technical note

The game uses the Canvas API to draw play, `requestAnimationFrame` for its game loop, and local JPG images for the background and ball. It has no frameworks or game engine.
with simple HTMl, CSS and JS framework

## Play


- Use **W** or **Up Arrow** to move your paddle up.
- Use **S** or **Down Arrow** to move your paddle down.
- First to 11 points wins. Choose **Play Again** to start a new match.

The computer paddle follows the ball when it reaches the computer's side of the court. Its speed changes during the match.
